# Подготовка развёртывания

## Проверенный образ

- Образ: `ghcr.io/muzraev/devops-ci-app`.
- Выбранный SHA: `aa798123d0404526280cc3f6de9ea0bc60eaddca`.
- Digest: `sha256:be4c4064895841d45fa2f69afeba1508b6be8ae7fd223974a6c0f95868855832`.
- Пакет публичный: для docker pull аутентификация не требуется.
- Проверка вне CI: оба тега загружаются, `/health` возвращает `{"status":"ok"}`, пользователь контейнера — `app`, UID 999.

## Для Ansible

В inventory нужно указать фактический адрес VM, SSH-пользователя и SSH-порт. Ключи и пароли не включаются в репозиторий.

В переменных приложения нужны имя образа, выбранный SHA или digest, имя контейнера, порт контейнера 5000 и сопоставление порта хоста. Проверка latest выполнена на 127.0.0.1:5001, SHA — на 127.0.0.1:5002. Health endpoint: `/health`.

Playbook должен загрузить проверенный образ, запустить контейнер и проверить health endpoint. Пересборка приложения на VM не требуется. Тег latest изменяется после успешных публикаций; SHA фиксирует выбранный исходный коммит, digest — содержимое образа.

После проверки удалены только временные контейнеры ci-app и ci-app-sha. Образ и пакет сохранены для практической работы 11.
